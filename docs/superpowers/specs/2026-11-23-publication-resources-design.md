# Publication resources design

The approved design replaces the italic conference line and bracketed resource links on both publication pages with a compact, wrapping publication bar. The conference becomes a small burgundy-tinted badge. Paper is a solid burgundy button; arXiv is an outlined secondary button. Both controls have rounded corners, clear hover and keyboard-focus states, and a minimum 44px height.

Use a single shared stylesheet and identical semantic markup on Generative Proxy and AR Embedded Visualizations. Preserve all resource destinations, surrounding content, and existing page branding. Allow the venue and links to wrap naturally on small screens. Verify both pages visually at desktop and mobile widths, plus check the diff for whitespace errors and unintended changes.
